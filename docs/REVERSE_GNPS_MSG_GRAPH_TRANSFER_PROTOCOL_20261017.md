# Inverse archive provider transfer: metadata-only locked scientific protocol

Date 2026-10-17. Graph method frozen at commit 64aced60540b5d57e191ff0ead73b445c71e1732 and prior retrospective positive outcome run 39058512753 (+0.001144 MRR, 95% formula CI [+0.000123,+0.002258], p=.032019). This FOLLOW-UP is explicitly motivated by that observed result. It cannot be a fully independent preregistered trial.

## Primary objective
Assess whether the exactly unchanged, fixed 0.90 Hellinger + 0.10 candidate-molecular-graph score transfers when source and reference providers are reversed: source GNPS reference scans become **measured GNPS queries** and MassSpecGym scans become **candidate reference library**. The original forward experiment used MassSpecGym queries and GNPS references. No new experimental acquisition has been proven independent. This is the same underlying combined harmonized archive, so only call it **directional archive transfer**.

Original source Zenodo DOI 10.5281/zenodo.20042904, SHA256 aee5a595960ef1284fe9977b6560a1ff771c07bb28c4a8e2e2ef47020b35724e. Input native metadata fields required: SOURCE_DATASET, full InChIKey, formula, native mode and precursor mass; reference SMILES must be checked against its own molecular formula. Target/query SMILES and query truth are not used in model feature generation.

### Stage A: no-peaks metadata lock (run separately, before any scoring)
Stream ALL headers of all 443,905 source records via existing native parsing; do not parse any m/z-intensity fragment pairs, retrieve query SMILES, or examine model outcomes. Set reference provider=MassSpecGym; GNPS queries. For reference, keep at most two scans per full InChIKey + formula + mode + 0.01Da precursor bucket, using SHA256-based deterministic stable selection. For GNPS queries, select exactly one scan per full InChIKey+formula+mode BEFORE determining if the correct structure appears in the reference library. Keep all eligible positive and negative modes, no reweighting or separately reselected polarity cohort. Exact precursor matching tolerance max(.02Da,20ppm), same native formula and ion mode, candidate pool must include >=2 chemically distinct native full InChIKeys including the true label. Reject only metadata-ineligible queries, never score-derived queries.

Predetermined feasibility: >=100 hard queries, >=50 distinct correct full InChIKeys, >=20 native formula blocks. The scientific gate may fail and, if it does, **STOP WITHOUT SCORING**, publish zero-peaks feasibility and do not retroactively loosen thresholds. Write complete manifest and native metadata/source hash artifacts. No minimum each polarity, decided now ahead of metadata outcomes; report polarity coverage and never extrapolate to a mode lacking data.

### Stage B: after Stage A passes and its immutable artifact/run ID is recorded
Do not change graph code, graph shifts, matching, 0.01Da threshold, two non-ring cut combinatorics, native SMILES handling, reference scan aggregation, formula definitions, 0.9/0.1 score mix, or candidate pooling. Apply fixed Hellinger and fixed graph mixture across ALL frozen reversed hard queries, regardless of what isomers are chemically easy or graph-ineligible. Any missing or invalid reference candidate SMILES gets graph score 0 and remains eligible. All actual structure labels only used to calculate final rank after scores are fixed.

Single primary comparison: mean MRR(frozen graph-conditioned) minus mean MRR(original Hellinger), formula-block clustered 10,000 bootstrap draws and 50,000 whole-formula paired signflips (two-sided). Declare limited **within-archive directional transfer success** only if delta positive, formula 95% bootstrap CI lower >0, p<.05, no exact duplicate intensity-matched query/ref spectra, and the V1 gate passed. Retain all negative and failed cases. Report fractional top1, query-structure overlap with previous forward experiment, formula overlap, provider instrument provenance, graph chemistry eligibility, true-query MRR win/loss/tie, chemical formulas and native mode counts.

### Scientific limits
Original graph method was selected after many related failures and was developed on SAME harmonized combined archive. Even a successful reversed-direction experiment is only supportive and potentially correlated. It cannot establish a de-novo novel-molecule discovery advance, independence of acquisitions, CASMI hidden-test performance, or a physics law. A second physically independent laboratory archive with structural truth as candidate-only, a fully locked method, an actually unseen formula/structure cohort, and strong neural/library competition baselines remains essential. No source-derived conclusions before all metadata/score gates and complete artifact are audited.

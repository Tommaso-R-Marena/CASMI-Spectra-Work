# Stronger entropy comparator protocol: freeze before opening new rarity result

Date: October 17 2026. Stacked on fixed exploratory rarity branch e310866f661635c92eddf4908df6fcdc1aee7955, separately branched as research/spectral-entropy-vs-reference-rarity-20261017. This protocol was constructed while initial rarity scorer #39057144654 remained in-progress, before its MRR outcome became known. HOWEVER source GNPS/MassSpecGym outcomes from the original support-composite run were already public. Consequently no independent prospective claims whatsoever.

Scientific rationale: Published spectral-entropy similarity (Li et al., Nature Methods 2021, DOI 10.1038/s41592-021-01331-z) is a stronger established MS/MS comparator than plain cosine alone. We implement a direct UNWEIGHTED Jensen-Shannon spectral similarity baseline, not the intensity-weighted entropy-search version. We must not claim to have beaten the original weighted entropy search or any modern learned model.

Input: exact originally pinned harmonized source SHA256 aee5a595960ef1284fe9977b6560a1ff771c07bb28c4a8e2e2ef47020b35724e, DOI 10.5281/zenodo.20042904, old two-polarity FAIL gate and positive-only V2 PASS gate; query and reference manifests unmodified and replayed. Original 4,398 chemical structures, 2,254 chemical formulas, only positive ion mode, native same-formula/precursor/polarity candidate pool.

Control scorer: P and Q are full unmodified L1-normalized fragment vectors, matched with the original greedy closest m/z one-to-one tolerance 0.01Da. Unmatched mass remains in the denominators. JSD = H((P+Q)/2)-(H(P)+H(Q))/2 using a union of distinct matched fragment ions and separately represented unmatched ions; entropy similarity=1-JSD/ln(2). Equivalently, sum over positive matched masses of [(a+b)ln(a+b)-a ln a-b ln b]/(2ln2), as in the accompanying separately tested implementation. Aggregate candidate repeats using the same maximum-scan rule.

One joint predeclared exploratory question: does the ALREADY FIXED reference rarity 0.5 Hellinger + 0.5 rarity-Hellinger scorer beat both original Hellinger AND unweighted entropy on mean reciprocal rank with both contrasts positive, both formula-cluster 95% bootstrap lower bounds >0, and both two-sided formula-cluster signflip Holm-adjusted p<.05? Seeded 5,000 formula-block bootstrap and 50,000 signflips. Report original cosine and support composite for context; unweighted entropy-vs-Hellinger is a descriptive contrast. Do not move goalposts after the benchmark is opened.

Limitations and strict future standard: positive outcomes would remain retrospective on an already evaluated archive, not evidence of unique novel fragmentation physics, independence of laboratory recording, carefully curated structural ground truth, official CASMI 2026 performance, or superiority over original entropy intensity transformation. A new, fully blinded and independently collected molecular spectrum set with prespecified candidate construction must demonstrate improvement over strong contemporary baselines and multi-instrument confound checks. Negative outcomes are equally meaningful and must remain in the public draft.
